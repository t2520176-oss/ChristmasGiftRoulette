# Lil Reaper 키링 (Bambu Studio 3MF)

`Lil_Reaper_Keychain.3mf` — 원본 `Meshy_AI_Lil_Reaper_1.3mf`를 출력용으로 수정한 파일입니다.
4색(갈색·흰색·분홍·검정) 도색 정보는 그대로 들어 있습니다.

## 무엇을 고쳤나

| 문제 | 원인 | 조치 |
|---|---|---|
| 얼굴 패임 | 왼쪽 눈 위의 균열/단차 흉터, 노즐보다 가는 홈(0.1~0.2mm) | 메시 복구(비수밀·뒤집힌 면·떠다니는 조각 54개 제거) + 얼굴 이마 부위만 국소 평활화 |
| 서포트 과다 | 후드가 몸통보다 넓은 버섯 모양, 턱 밑·후드 챙·자루 아래 오버행 | 오버행 아래를 38° 경사로 메움(둥근 뒷면은 그대로). 후드~망토 이음이 완만해짐 |
| 고리 | 구멍 3.2×2.8mm(키링 링이 안 들어감), 가늘고 약함 | 구멍 약 5mm, 벽 약 2.7mm, 두께 3.6mm로 새로 제작. 윗부분은 티어드롭형(서포트 불필요) |
| 낫 | 위치·모양 유지, 더 튼튼하게 | 자루 반지름 +0.8mm, 날 두께 4.8→6.6mm(앞뒤 중심선 불변, 정면 실루엣 일치율 99.5%) |

## 출력 안내

- 방향: 그대로(세워서). 베드 중앙에 배치되어 있습니다.
- 크기: 약 53.5 × 33.8 × 52 mm (원본의 66%). 슬라이서에서 자유롭게 조절 가능.
- 3MF에 서포트 설정이 들어 있습니다: 트리(자동) / 빌드 플레이트 전용 / 임계각 30°.
  낫 날 끝 부근에만 생성될 것으로 예상합니다.
- 얼굴 영역에는 서포트 차단(blocker) 페인팅을 넣었습니다. Bambu Studio에서 인식되는지는 확인하지 못했으니,
  서포트 페인팅 도구에서 얼굴이 칠해져 있는지 한 번 확인해 주세요.
- 권장: 레이어 0.12mm, 노즐 0.4mm, 벽 3줄 이상, 인필 15~20%.
- 4색 교체가 많아 프라임 타워 낭비가 큽니다. 플러시 배수를 줄이는 것을 권합니다.

## 한계

- 메운 부분과 고리는 검정으로 칠했습니다.
