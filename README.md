# OurChat source delivery

This isolated branch contains the independent OurChat project archive.

Download `OurChat.zip` using its GitHub file page and the Download raw file button. Extract the archive, then follow `ourchat-private/README.ko.md` or `README.md`.

The ZIP includes the application source, SQL migrations, setup instructions, tests and empty environment template. It contains no service credentials, real account identities, node_modules or build output. External Supabase/Vercel setup is still required.

The ChristmasGiftRoulette app is not changed by this delivery branch.
