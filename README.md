# OurChat Windows 자동 설치

[설치 파일 다운로드 — OurChat-Setup.cmd](https://github.com/t2520176-oss/ChristmasGiftRoulette/raw/refs/heads/codex/ourchat-download/OurChat-Setup.cmd)

Windows 10/11 64비트 PC에서 파일을 다운로드하고 더블클릭하세요. ZIP 압축 해제나 명령어 입력 없이 Node.js·앱 설치, 빌드, 바탕화면 바로가기 생성과 브라우저 열기를 진행합니다. 첫 설치에는 인터넷 연결이 필요합니다.

설정 창에서 Supabase URL과 publishable 키를 입력합니다. **Skip / keep settings**를 누르면 미리보기로 실행됩니다. Supabase 프로젝트·SQL·두 사용자 계정 설정은 실제 채팅을 위해 한 번 필요합니다. 휴대폰에서 함께 쓰려면 별도 HTTPS 배포가 필요합니다. 자세한 설명은 설치 후 **Setup guide**에서 확인하세요.

설치 후 바탕화면 **OurChat**으로 실행하고 **OurChat Settings**에서 연결값을 변경합니다. 앱 사용 중 콘솔 창을 열어 두고 Q로 종료하세요. 재설치해도 기존 설정과 알림 키는 보존합니다.

이 파일은 Windows 실기기 설치를 검증하지 않았습니다. 클라우드에서 설치/설정 helper 검사 37개, PowerShell 구문, ZIP·체크섬 및 앱 lint/TypeScript 검사를 통과했습니다.

설치 파일 링크가 브라우저에 텍스트로 열리면 [파일 페이지](https://github.com/t2520176-oss/ChristmasGiftRoulette/blob/codex/ourchat-download/OurChat-Setup.cmd)의 **Download raw file (↓)**로 저장하세요.
