# 03 · Halloween Ghost Keyring — 마녀 모자 유령 + 이름 키링 (4색)

사진의 특징(마녀 모자를 쓴 유령, 굵은 이름, 별, 검정 판, 테두리, 오른쪽 위 고리)을 살려 **도형으로 새로 설계**한 키링입니다.
크기 **약 51 × 54 × 3.6 mm**. 색은 **4가지(AMS 1대)**: 흰색 · 검정 · 연두 · 분홍.

![preview](out/4color/preview_top.png)

## 파일
| 파일 | 색 | 들어 있는 것 |
|---|---|---|
| `scad/keyring_4color.scad` | — | **OpenSCAD 원본**(색 지정 포함, 이름·크기 수정 가능) |
| `1_white.stl` | 흰색 | 테두리, 고리, 유령 몸 |
| `2_black.stl` | 검정 | 판, 마녀 모자, 눈, 입 |
| `3_green.stl` | 연두 | 이름, 별, 모자 버클 |
| `4_pink.stl` | 분홍 | 볼터치, 혀, 모자 띠 |
| `onecolor_no_AMS.stl` | 한 색 | 전부 합친 단색 버전(AMS 없을 때, 칠해서 완성) |

4개 부품은 **같은 좌표**라 함께 불러오면 제자리에 맞춰집니다.
원래 사진처럼 금색 별·보라 띠가 필요하면 7색 버전(`scad/keyring_7color.scad`, `out/7color/`)도 들어 있습니다.

## Bambu Studio에서 출력 (AMS)
1. STL 4개를 **한꺼번에 선택**해서 끌어다 놓습니다.
2. "여러 부품을 하나의 객체로 불러오시겠습니까?" → **예**.
3. 부품마다 필라멘트 지정: 1번 흰색, 2번 검정, 3번 연두, 4번 분홍.
4. 레이어 0.2mm, 서포트 끄기 → 슬라이스 → 출력.

## OpenSCAD에서 직접 (원본 파일)
- `part = "all"` → 4색 미리보기(F5)
- `part = "white"` / `"black"` / `"green"` / `"pink"` → F6 → STL로 내보내기(색마다 한 번씩)
- `part = "onecolor"` → 단색 STL
- 맨 위 `name_text = "Liam";` 에서 **이름 변경**. 글자 크기는 자동으로 판 안에 맞춰집니다(`name_fit_w`).
- 한글 이름: `font_name = "Malgun Gothic:style=Bold";` (Windows)
- 크기: `model_scale`(0.9 → 약 51mm). 높이(층)는 줄어들지 않게 x·y만 조절합니다.
- 최신 OpenSCAD에서 3MF로 내보내면 색이 함께 저장될 수 있지만, Bambu Studio에서 필라멘트 지정은 직접 해야 하는 경우가 많습니다. 가장 확실한 방법은 STL 4개입니다.

## 구조 (층, 모두 0.2mm 배수)
흰색 테두리 0~1.6mm → 검정 1.6~2.8mm → 색 요소 2.8~3.6mm. 고리는 흰색이 2.8mm까지 올라가 튼튼합니다. 고리 구멍 약 4.3mm.

## 검증 현황
**검증됨(수치)**: 4색 부품과 단색 부품 모두 닫힌 메시(비다양체 모서리 0), 색 부품 6쌍 겹침 0(색이 섞이지 않음), P2S 베드 안,
이름 6개(Liam, Ava, Noah, Sophia, Alexander, Jo)가 판 안에 여백 2.4mm 이상으로 자동 맞춤.
**검증되지 않음**: 실제 출력 결과, AMS 색 전환 시 퍼지 양과 시간, 가장 작은 눈(폭 약 2.3mm)의 출력 품질,
한글 폰트(이 환경에는 Malgun Gothic이 없어 시험 못 함: 한글은 글자당 1em으로 어림해서 크기를 맞춥니다), Bambu Studio 메뉴 이름(버전마다 다를 수 있음).
