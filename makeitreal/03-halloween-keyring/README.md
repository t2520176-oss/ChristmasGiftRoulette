# 03 · Halloween Ghost Keyring — 마녀 모자 유령 + 이름 키링

사진의 특징(마녀 모자를 쓴 유령, 굵은 연두색 이름, 금색 별, 검정 판, 크림색 테두리, 오른쪽 위 고리)을 살려서
**도형으로 새로 설계한** 키링입니다(사진을 따라 그린 것이 아닙니다). 크기 **51 × 54 × 3.6 mm**.

![preview](out/preview_top.png)

## 파일
(압축 파일 안의 이름 기준입니다. 저장소 `out/` 폴더에서는 번호 없이 `cream.stl` 등으로 들어 있습니다.)
| 파일 | 색 | 들어 있는 것 |
|---|---|---|
| `1_cream.stl` | 크림/베이지 | 테두리 + 열쇠고리 구멍 |
| `2_black.stl` | 검정 | 판, 마녀 모자, 눈, 입 |
| `3_white.stl` | 흰색 | 유령 몸 |
| `4_green.stl` | 연두 | 이름 "Liam" |
| `5_gold.stl` | 금색/노랑 | 별, 모자 버클 |
| `6_purple.stl` | 보라 | 모자 띠 |
| `7_pink.stl` | 분홍 | 볼터치, 혀 |
| `onecolor.stl` | 한 색 | 위 전부를 하나로 합친 단색 버전 |

7개 부품은 **같은 좌표**에 있어서 함께 불러오면 정확히 제자리에 맞춰집니다.

## 멀티컬러로 출력 (Bambu Studio + AMS)
1. 7개 STL(`1`~`7`)을 **한꺼번에 선택해서** Bambu Studio로 끌어다 놓습니다.
2. "여러 부품을 하나의 객체로 불러오시겠습니까?" 같은 질문이 나오면 **예**.
3. 오른쪽 객체 목록에서 부품을 하나씩 눌러 **필라멘트 색**을 지정합니다(위 표의 색).
4. 레이어 0.2mm, 서포트 끄기, 채움 100%(얇은 판이라 상관없음), 슬라이스 → 출력.

**AMS가 4칸뿐이면** 이렇게 합치세요: 크림→흰색, 분홍→흰색(볼터치는 나중에 마커로), 보라→검정, 나머지는 그대로.
(색을 합친 부품은 같은 필라멘트로 지정만 하면 됩니다. 파일을 바꿀 필요 없음.)

## AMS가 없으면
`onecolor.stl`을 한 색(흰색 추천)으로 출력한 뒤, 튀어나온 부분을 **아크릴 마커/물감**으로 칠하세요.
글자·별·모자·유령이 3.6mm까지 도드라져 있어서 칠하기 쉽습니다.

## 이름 바꾸기
`scad/keyring.scad` 맨 위의 `NAME = "Liam";` 만 바꾸고 다시 내보내면 됩니다(OpenSCAD 필요).
어려우시면 이름만 알려주세요. 제가 새 파일을 만들어 드립니다. 이름이 길면(7글자 이상) 글자를 줄여야 합니다.

## 구조 (층)
크림 0~1.6mm → 검정 1.6~2.8mm → 색 요소 2.8~3.6mm(0.2mm 레이어의 정수배). 고리는 크림이 2.8mm까지 올라가 튼튼합니다.
고리 구멍 지름 약 4.3mm(일반 열쇠고리 링이 들어갑니다).

## 검증 현황
**검증됨(수치)**: 부품 7개 모두 닫힌 메시(비다양체 모서리 0), 색 부품 21쌍 서로 겹치는 부피 0(색이 섞이지 않음), P2S 베드 안.
**검증되지 않음**: 실제 출력 결과, AMS 색 전환 시 퍼지(버려지는 필라멘트) 양과 시간(작은 키링에 비해 많을 수 있음, 대략 1~2시간 추정),
슬라이서 메뉴 이름(버전마다 조금 다를 수 있음), 가장 작은 부분(눈 폭 약 2.3mm)의 출력 품질.
