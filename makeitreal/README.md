# Make It Real 2026 — 출품작 10선

ELEGOO DAY "Make It Real" (Nexprint, 2026-09-10 ~ 10-30). 내 손그림·아이디어를 직접 설계해서 실물로.
프린터: Bambu Lab P2S (FDM). 도구: OpenSCAD, Python(+ Blender는 렌더용).

심사: 주제 관련성 0.2 · 창의성/미학 0.35 · 구조/기능성 0.3 · 발표 완성도 0.15 — 실물 출력이 있어야 1~3등 후보.

| # | 작품 | 변환 원리 | 상태 |
|---|---|---|---|
| 1 | [Sketch Walker](01-sketch-walker/) | 낙서 → 몸통, 아이디어 → 6절 링크 보행 기구 | 설계·검증 완료, **보류**(핀 44개·모터·배선으로 제작 난도 높음) |
| **2** | [Hidden Doodle Lantern](02-hidden-doodle-lantern/) | 그림 → 벽 두께에 숨김 → 불 켜면 떠오름 | **설계·검증 완료 / 출력 전 (쉬움: 출력 1번)** |
| 3 | Parallax Window | 한 장의 그림 → 5겹 시차 | 대기 |
| 4 | Triple-Silhouette Block | 실루엣 3장 → 하나의 입체 | 대기 |
| 5 | Labyrinth Lock Box | 손으로 그린 미로 → 원통 홈 잠금함 | 대기 |
| 6 | Halftone Mail | 사진 → 프린트인플레이스 천 | 대기 |
| 7 | Marble Logic | 논리회로 스케치 → 구슬 컴퓨터 | 대기(도전작) |
| 8 | Bloom | 꽃 스케치 → 펼쳐지는 꽃 | 대기 |
| 9 | Drawing Zoetrope | 12프레임 손그림 → 3D 조트로프 | 대기 |
| 10 | Spiral Tree | 납작한 나선 → 입체 트리 (보험작) | 대기 |

규칙: 대회 기간 중 새로 만든 설계만, 원본 스케치/이미지를 첫 사진에, 타 플랫폼에 먼저 공개하지 않기, 작품 간 개념 중복 금지.

## 새 선정 기준 (제작이 쉬울 것)
부품 3개 이하 · 모터/전자/핀/접착 없음 · **서포트 없음** · 출력하면 끝(LED 티라이트 정도만 추가).
- 탈락: Triple-Shadow(2D/3D 그림자 조각) — 계산해 보니 지지대 부피가 본체의 절반이고 조각 하나가 떠 있어 연결되지 않음.
- 보류: Sketch Walker(고난도), Marble Logic, Bloom, Zoetrope(조립·전자부품).
- 다음 후보(쉬운 순): Halftone Mail(조립 없는 프린트 천), Spiral Tree, Labyrinth Lock Box(부품 3개), Parallax Window(판 5장 꽂기).
