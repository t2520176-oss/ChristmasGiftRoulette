# 🎃 Spooky Pals — 갈아입히는 할로윈 펫 받침대

> **6종 펫 × 6종 의상 × 3종 받침 = 108가지 조합**을 하나의 OpenSCAD 파일로 만들고,
> **서포트 없이** 출력되도록 설계했으며, Blender로 전시용 이미지를 렌더링한 3D 프린트 작품입니다.

![라인업](renders/01_lineup.png)

> ⚠️ **먼저 읽어 주세요 (솔직한 상태 보고)**
> 이 저장소는 클라우드 환경에서 만들어졌고, 여기에는 **3D 프린터가 없습니다**. 그래서 "서포트 없음"은 실제 출력이 아니라
> **STL을 층(0.2 mm) 단위로 잘라 허공에 뜨는 면적을 계산하는 자체 검사 도구**(`tools/printcheck.py`)와 부품 간섭 검사(`tools/fitcheck.py`)로
> 확인한 값입니다. 결과는 [`docs/PRINT_REPORT.md`](docs/PRINT_REPORT.md)에 있습니다.
> **대회 제출 전에 펫 본체 1개만이라도 시험 출력**해서 끼움 공차(`tol`)와 표면 품질을 확인하길 권합니다.

## 1. 레퍼런스 사진과 무엇이 다른가 (독창성 포인트)

사진의 컨셉(할로윈 의상을 입은 펫 + 이름이 새겨진 받침)은 그대로 따르되, **형상은 전부 코드로 처음부터 모델링**했고
(사진을 트레이싱하거나 외부 메시를 쓰지 않았습니다) 아래 부분에서 차별화했습니다.

| # | 차별점 | 레퍼런스 | Spooky Pals |
|---|---|---|---|
| 1 | **의상 스왑 시스템** | 의상이 몸에 조각돼 있어 바꿀 수 없음 | 모든 펫이 **같은 몸통·머리 규격**을 쓰고, 모자·망토·참이 **별도 부품**. 아무 펫에 아무 의상이나 끼웁니다. 귀·꼬리가 있는 자리는 모자·망토가 **자동으로 파여** 맞춰집니다. |
| 2 | **서포트 제로 엔지니어링** | – | 모든 부품을 "출력 자세 그대로" 모델링: 바닥 평면, ≤45° 경사, 뾰족한 소켓 천장, 바닥에 닿는 박쥐 날개 끝, 뾰족 아치 등. 자체 검사 도구로 수치 검증. |
| 3 | **쐐기형 이름 간판** | 수직 명패 | 받침 앞에 **30° 쐐기 램프**를 붙이고 거기에 이름·발바닥을 양각(또는 음각). 서포트 없이 선명하고, 위에서도 정면에서도 잘 읽힙니다. 이름은 글자 폭에 맞춰 자동 축소. |
| 4 | **캐릭터형 모자** | 일반 모자 | 머리 위에 **미니 박쥐**(흡혈귀), **미니 유령**, **잭오랜턴 호박**(얼굴 음각), **악마 뿔**, 마녀/마법사 모자(별 장식) |
| 5 | **받침 3종 (+ 소품)** | 그루터기 / 묘지 / 단순 | **호박밭 그루터기**, **납골당(팔각 석재 + 묘비 + 뼈)**, **마녀 가마솥(초록 점액 + 흘러내림)** |
| 6 | **멀티컬러 즉시 지원** | – | `multicolor = true`로 **11개 색 파트**(털·흰 무늬·눈·눈빛·모자·장식·망토·참·받침·소품·이름)로 분리. AMS/MMU 슬라이서에서 파트별 필라멘트만 지정. |
| 7 | **자석 옵션** | – | `magnets = true`로 5×2 mm 자석 포켓 생성 → 의상을 철컥 갈아입힙니다. |
| 8 | **한 파일 파라메트릭** | – | `openscad/spooky_pals.scad` 하나로 Customizer(Printables / MakerWorld 등)에서 바로 사용. |

## 2. 구성

* **펫 6종**: 강아지 · 고양이 · 토끼 · 햄스터 · 새 · 다람쥐 (각자 귀 / 꼬리 / 주둥이 / 날개)
* **의상 6종** (각각 `모자 + 망토 + 참`)
  | 의상 | 모자 | 망토 | 참 |
  |---|---|---|---|
  | vampire | 미니 박쥐 | 뾰족 칼라 + 톱니 밑단 | 리본 |
  | witch | 구부러진 뾰족모자 + 띠 + 버클 | 톱니 밑단 짧은 망토 | 리본 |
  | ghost | 미니 유령 (눈·입 음각) | 물결 시트 | 미니 호박 |
  | pumpkin | 잭오랜턴 호박 | 세로 홈이 있는 호박 껍질 망토 | 잎 |
  | devil | 구부러진 뿔 | 박쥐 날개 망토 | 리본 |
  | wizard | 키 큰 모자 + 별 | 긴 망토 | 별 브로치 |
* **받침 3종**: `stump` · `crypt` · `cauldron`
* **이름**: A–Z, 0–9, 공백 (약 9자까지, 길면 자동으로 작아짐)

## 3. 출력 가이드

### 파트와 출력 방향
`part` 값을 바꿔 STL로 내보내면 **전부 출력 자세로 바로 나옵니다**(`layout = "print"`).
`part = "plate"`는 한 세트 전체를 220 × 220 mm 베드에 배치합니다.

| 파트 | 출력 방향 | 비고 |
|---|---|---|
| `base` | 바닥면(받침 밑면)이 베드 | 쐐기 간판 경사면이 윗면 → 서포트 없음 |
| `pet` | 발바닥 평면이 베드 | 머리 아래 곡면의 아주 작은 오버행(< 부피의 0.1 %)만 있음 |
| `hat` | 평평한 밑면이 베드 | 박쥐는 날개 끝 5개가 바닥에 닿는 구조 |
| `cape` | 밑단이 베드 | 뒤쪽을 감싸는 얇은 쉘(2.2 mm). 브림 권장 |
| `charm` | 뒷면(평평한 면)이 베드 | 작은 부품. 순간접착제/양면테이프로 가슴에 부착 |

### 슬라이서 권장값 (PLA, 0.4 mm 노즐 기준)
* 층 높이 **0.2 mm**, 벽 **3겹**, 채움 **12–15 % (자이로이드)**, **서포트 끔**
* 냉각 100 %, 첫 층 이후 속도 40–60 mm/s (작은 부품은 층 최소 시간 8–10 s 권장)
* 망토만 **브림 3–5 mm** 추천 (바닥 접촉이 얇은 링 모양이라서)
* 출력 시간은 프린터마다 달라 표기하지 않았습니다. 펫은 약 17–20 g, 받침은 약 25–30 g 정도의 PLA를 쓸 것으로 **추정**합니다(`PRINT_REPORT.md`의 "est. PLA" 열).

### 색 추천
* 펫: 검정/회색/크림/노랑/갈색, 흰 무늬는 별도 색 (`multicolor`)
* 눈·코·입: 검정 (눈빛은 흰색 한 방울 — 따로 안 뽑고 흰 펜으로 점만 찍어도 됩니다)
* 이름 글자: 크림색 / 야광(글로우) 필라멘트도 잘 어울립니다

### 멀티컬러 (AMS / MMU)
`multicolor = true`, `layout = "assembled"`로 **모든 파트를 같은 좌표계**로 내보내 슬라이서에서
"하나의 객체의 여러 파트"로 불러오면 위치가 그대로 맞고, 파트마다 필라멘트를 지정하면 됩니다.
(PrusaSlicer: "여러 파일을 하나의 객체로 불러오기 → 예")

## 4. 조립

1. **펫 → 받침**: 펫 발바닥 소켓을 받침의 타원 돌기(원뿔)에 꽂습니다. 방향은 180° 두 가지뿐이라 이름판이 앞을 보게 맞추면 됩니다.
2. **모자 → 머리**: 머리 정수리의 원뿔 돌기에 모자 밑면 소켓을 끼웁니다 (귀가 모자 테두리의 홈과 맞물립니다).
3. **망토 → 뒤에서**: 망토를 **뒤에서 앞으로** 밀어 넣으면 등 위쪽의 작은 돌기 2개에 "딸깍" 걸립니다. 밑단은 받침 위에 놓입니다.
4. **참(리본 등)**: 가슴 흰 털 위에 순간접착제 한 방울.
5. 헐거우면 `tol`(기본 0.15 mm)을 0.10으로, 너무 빡빡하면 0.20–0.25로 조정해 다시 내보내세요. 자석 옵션을 쓰면 접착이 필요 없습니다.

## 5. OpenSCAD 사용법 (Customizer)

```bash
openscad openscad/spooky_pals.scad                 # GUI: 오른쪽 Customizer 패널에서 값 선택
openscad -o dog.stl -D 'part="pet"' -D 'pet="dog"' openscad/spooky_pals.scad
```

| 파라미터 | 값 | 설명 |
|---|---|---|
| `part` | `assembled` `plate` `pet` `hat` `cape` `charm` `base` + (멀티컬러) `marks` `face` `shine` `trim` `deco` `text` | 무엇을 보여주고/내보낼지 |
| `pet` | dog cat rabbit hamster bird squirrel | 펫 종류 |
| `costume` | none vampire witch ghost pumpkin devil wizard | 의상 (`none` = 맨몸) |
| `base_style` | stump crypt cauldron | 받침 |
| `name` | 문자열 | 이름 |
| `layout` | print / assembled | 출력 자세 / 조립 위치 |
| `multicolor` | true/false | 색 파트 분리 |
| `magnets` | true/false (+ `magnet_d`, `magnet_h`) | 자석 포켓 |
| `raise_text` | true/false | 양각/음각 이름 |
| `base_decor` | true/false | 받침 소품 |
| `model_scale` | 숫자 | 전체 크기 (1 = 모자 포함 약 92 mm) |
| `tol` | 0.15 | 끼움 공차 |
| `fn` | 24(미리보기) – 48(최종) | 곡면 분할 수 |

* **OpenSCAD 2021.01 이상**에서 동작합니다 (2021.01에서 검증). 최종 STL은 `fn = 40`으로 내보내며, 세트 하나가 몇 분 걸립니다.
  Manifold 백엔드가 있는 최신 OpenSCAD(`--backend=manifold`)를 쓰면 훨씬 빠릅니다.
* 글꼴: 기본 `Liberation Sans:style=Bold`(OpenSCAD 기본 포함). 갤러리 STL은 DejaVu Sans Bold로 내보냈습니다.

### 명령줄 도구 (`tools/`)

| 도구 | 용도 |
|---|---|
| `export_parts.py` | 한 세트의 모든 파트를 병렬로 STL(바이너리)로 내보내기 |
| `printcheck.py` | 출력 자세 STL의 닫힘·오버행·층별 허공 면적 검사 |
| `fitcheck.py` | 조립 상태에서 부품 간 간섭 부피/간극 검사 |
| `report.py` | 위 결과를 `docs/PRINT_REPORT.md`로 정리 |
| `make_showcase.py` | 갤러리 세트 내보내기 + Blender 렌더 일괄 실행 |
| `compose_panels.py` | "나만의 조합" 옵션 패널 이미지 합성 |

## 6. Blender 렌더

`blender/render_showcase.py`는 STL 세트 폴더를 읽어 파트별 재질(PLA 느낌 + 미세 범프)을 입히고,
따뜻한 키라이트 + 보라 림라이트 + 보케(배경 불빛) + 얕은 피사계 심도로 Cycles 렌더링합니다.
`blender/quick_view.py`는 설계 검토용 빠른 Workbench 렌더입니다.

```bash
python3 tools/make_showcase.py export --fn 40      # OpenSCAD -> stl/gallery/<이름>/
python3 tools/make_showcase.py panels --fn 40
python3 tools/make_showcase.py render --shots lineup,grid,hero,explode,panels --samples 128
```

## 7. 검증 결과 요약

[`docs/PRINT_REPORT.md`](docs/PRINT_REPORT.md) 참고. (자동 생성: `tools/report.py`)

__REPORT_SUMMARY__

**한계 (정직하게)**
* 실제 출력 테스트는 하지 못했습니다. 층 단위 계산은 슬라이서의 서포트 생성과 같은 결과를 보장하지 않습니다.
* 머리 아래 곡면(턱·볼)은 가슴 위로 최대 약 3–4 mm 돌출하는 작은 오버행입니다. 대부분의 프린터에서 서포트 없이 깨끗하게 나오지만,
  냉각이 약한 프린터에서는 표면이 조금 거칠 수 있습니다.
* 망토는 2.2 mm 얇은 쉘이라 낮은 채움에서도 속이 비칠 수 있으니 벽 3겹을 권합니다.
* 끼움 공차는 0.4 mm 노즐 기준 값입니다.

## 8. 폴더 구조

```
spooky-pals/
├─ openscad/spooky_pals.scad        ← 메인 파라메트릭 모델 (이것만 있으면 됨)
├─ openscad/props/scene_props.scad  ← 렌더용 소품 (출력용 아님)
├─ stl/gallery/<이름>/               ← 멀티컬러 조립 좌표 STL (슬라이서에서 하나의 객체로)
├─ stl/print/<이름>/                 ← 단색 출력 자세 STL + plate.stl
├─ renders/                          ← Blender 렌더 이미지
├─ blender/                          ← 렌더 스크립트
├─ tools/                            ← 내보내기·검증·리포트 도구
└─ docs/PRINT_REPORT.md              ← 출력 검증 리포트
```
